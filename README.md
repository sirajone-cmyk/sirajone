# SirajOne

SirajOne is a React + Vite app for Islamic community services, including:

- Learning and courses
- Counselling/support
- Madrasa/masjid ride workflows
- Library and reading features
- Student, teacher, parent, and admin workflows

## Tech Stack

- React 18
- Vite 5
- Tailwind CSS

## Scripts

- `npm run dev` - start local dev server
- `npm run dev:host` - start dev server on LAN
- `npm run build` - production build
- `npm run preview` - preview production build

## Deployment

This repository is ready for Vercel deployment.
